# Soary

Soary is a web-based drone control platform built at Hack the North 2021. It enables users to communicate with and control a drone through a browser interface.

## Overview

The project focuses on connecting hardware with the web by providing a simple interface for sending commands to a drone in real time.

## Tech Stack

Frontend
- React
- HTML
- CSS
- JavaScript

Backend
- Node.js
- Express
- Prisma

## Features

- Real-time communication with a drone via a web interface
- Command-based control system
- Full-stack architecture with API integration

## How It Works

The frontend sends requests to a Node.js backend, which processes the commands and communicates with a drone API. Prisma is used for data handling and backend structure.

## Project Context

Built during Hack the North 2021 as a hackathon project exploring hardware and web integration.
